**G1a-R1 — Descriptor reuse and range hardening (accepted by independent review).**
At `0x08863DD8`, `a2`/`gpr[6]` is the descriptor start; the generated ring
arithmetic has already advanced past the 12-byte prefix. Every valid commit
that overlaps a prior 32-byte descriptor span creates a fresh descriptor
generation and marks the previous one non-current. Reusing that address for an
unowned request to a disjoint destination invalidates the old descriptor token
without retiring its pending writer. A subsequent selected reuse creates a
third generation; the old writer remains live. Only valid RAM spans can be
classified as disjoint. Zero/overflowing/out-of-RAM spans fail closed, and a
selected request one byte beyond the 0x5800 owner slot retains the old and new
writer hazards before rejecting the descriptor. The exact 0x5800 boundary is
accepted as an observation but does not establish completion.
